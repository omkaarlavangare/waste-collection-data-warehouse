# Waste Collection Data Warehouse

## Overview
This project demonstrates the application of data warehousing and business intelligence (BI) analytics concepts using waste collection data. It focuses on designing an appropriate schema, performing advanced aggregations, and generating analytical insights through queries and visualizations.

## Objective
The objective of this project is to apply hands-on knowledge gained from the course by building and analyzing a waste collection data warehouse. The project emphasizes schema design, data loading, aggregation techniques, and data visualization.

## Project Tasks
- Analyze business requirements and determine the appropriate schema and level of detail
- Design the data warehouse schema and establish relationships between tables
- Load CSV data into PostgreSQL using pgAdmin 4
- Perform advanced aggregations using `GROUPING SETS`, `ROLLUP`, and `CUBE`
- Create materialized views for aggregated and optimized reporting
- Visualize waste collected by:
  - Truck type
  - Station
  - City

This project provides a practical understanding of data warehousing principles and BI analytics by transforming raw waste collection data into meaningful insights through structured design, efficient querying, and visualization.
